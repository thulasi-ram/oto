# oto docs site

A [Starlight](https://starlight.astro.build) mirror of oto's Markdown
documentation. It renders the docs that already live in this repository; it is
not a second place to write them.

**Nothing here is wired to CI and nothing is deployed.** No workflow builds this
directory and no host serves it. Treat it as a local reader for the docs, and as
the thing to check when a docs link or heading anchor is in doubt.

## Running it

```
npm install
npm run dev      # syncs, then serves on localhost:4321
npm run build    # syncs, then builds to ./dist/
```

`dev` and `build` both run the sync step first, so a stale mirror cannot survive
either command. `npm run sync-docs` runs it on its own.

## How the sync works

`scripts/sync-docs.mjs` copies Markdown from the repository into
`src/content/docs/` and turns it into Starlight pages:

| Source | Becomes |
|---|---|
| `README.md` | `guides/overview.md` |
| `CONTEXT.md` | `architecture.md` |
| `CONTRIBUTING.md` | `contributing.md` |
| `docs/concepts.md` | `concepts.md` |
| `docs/ORCHESTRATION.md` | `orchestration.md` |
| `docs/adr/*.md` | `adr/` |
| `docs/design/*.md` | `design/` |
| `docs/setup/*.md` | `setup/` |
| `docs/runbooks/*.md` | `runbooks/` (`README.md` becomes `index.md`) |

For each file it derives the frontmatter `title` from the first H1, strips that
now-redundant H1 from the body, and rewrites `*.md` links to the clean URLs
Starlight serves them at. The four directory mirrors are deleted and rebuilt on
every run, so a page removed from `docs/` does not linger.

The generated pages are committed, which means they can go stale between a
source edit and the next sync. Re-run the sync after any change under `docs/`,
or to `README.md`, `CONTEXT.md`, `CONTRIBUTING.md` or `docs/concepts.md`, and
commit the result with the source change.

## Layout

- `astro.config.mjs` — site config and the hand-written sidebar. Overview is
  listed explicitly; Design, ADRs, Setup and Runbooks are autogenerated from the
  mirrored directories, so a new file in one of those needs no config change.
- `src/content/docs/` — generated pages, plus the two hand-authored ones:
  `index.mdx` and anything else under `guides/` that is not `overview.md`.
- `src/styles/custom.css` — theme overrides.
- `public/` — static assets served as-is.
