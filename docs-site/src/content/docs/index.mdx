## Where to start

{/* ⛔ `LinkCard`, NOT `Card`. Starlight's `Card` renders an <article>: it has no
    href and never had one, so the six tiles here looked like navigation and
    were not clickable — the single most reported thing about this page. It is
    also why `stagger` is gone: that prop translateY()s every second tile 5rem
    down, which left Introduction and Architecture, the first row and the two a
    reader looks at first, sitting at different heights.

    The trade is the icons. `LinkCard` takes only `title`, `description` and
    anchor attributes — there is no `icon` prop — so the rocket/pencil/book set
    is gone in exchange for a real link and the arrow affordance that says so.
    Wrapping a `Card` in an <a> would keep both, and was rejected: the moment
    somebody puts a link in a card body it is a nested anchor, which is invalid
    and fails silently.

    ⛔ EVERY href BELOW CARRIES THE BASE BY HAND, for exactly the reason the hero
    actions above do — an anchor attribute is emitted verbatim. `npm run
    check-links` compares these against the routes the build actually wrote, so
    a wrong one fails the build naming this file.

    Three of these do not point at a section index because there is no such
    page: design/, adr/ and setup/ are autogenerated groups with no landing
    route. Each therefore points at that section's honest front door — the
    binding SPEC, the first ADR, the first setup step — rather than at a URL
    that would 404. runbooks/ does have an index, so it gets it. */}
